# 明日方舟角色数据爬虫

这是一个Python爬虫项目，用于从Bangumi网站和明日方舟Wiki获取角色数据，并将这些数据合并处理为适用于标签系统的JSON格式。

## 功能特点

- 从Bangumi网站爬取明日方舟角色信息
- 从明日方舟Wiki爬取干员详细数据（星级、职业、阵营、标签等）
- 自动匹配Bangumi角色与明日方舟干员数据
- 智能处理角色变体（例如"送葬人"和"圣约送葬人"）
- 支持离线模式，减少重复请求
- 保留已有的自定义数据，同时更新可更新的内容
- 生成符合标签系统要求的JSON格式数据
- 对数据进行结构化处理，便于筛选和搜索

## 最新改进

- **变体处理优化**：使用预定义的变体映射表替代自动检测，避免错误的变体识别
- **独立变体识别**：自动识别Bangumi上已有独立条目的变体，避免错误合并
- **数据合并智能化**：合并数据时保留已有的自定义标签和内容
- **清理冗余数据**：当有有效数据时自动清理"未知"数据
- **标签格式优化**：将连续标签如"远程位输出"改为"远程位/输出"，并拆分为多个键值对
- **阵营信息处理**：将逗号分隔的阵营信息拆分为多个独立键值对

## 使用方法

### 环境要求

- Python 3.6+
- 依赖包：requests, beautifulsoup4

### 安装依赖

```bash
pip install requests beautifulsoup4
```

### 运行

#### 在线模式（获取最新数据）

```bash
python main.py
```

#### 离线模式（使用缓存数据）

```bash
python main.py --offline
```

### 输出文件

- `bangumi_characters.json` - Bangumi角色数据缓存
- `arknights_operators.json` - 明日方舟Wiki干员数据缓存
- `name_to_id_mapping.json` - 角色名称到ID的映射
- `extra_tags.json` - 最终生成的标签数据（主要输出）

## 数据处理说明

1. **角色匹配逻辑**：
   - 尝试精确匹配角色名称
   - 如未找到，尝试模糊匹配（名称包含关系）
   - 如仍未找到，保留已有数据或添加默认"未知"数据

2. **变体处理逻辑**：
   - 使用预定义的变体映射表识别角色变体
   - 自动识别Bangumi上已有独立条目的变体，避免错误合并
   - 自动检测潜在的变体关系，为每个基础角色聚合所有变体信息

3. **数据格式处理**：
   - 标签以分隔形式拆分为多个独立键值对
   - 阵营信息按逗号分隔为多个独立键值对
   - 职业和星级生成带图片的HTML标签

4. **数据合并策略**：
   - 保留已有数据中的自定义内容
   - 添加新识别的数据
   - 当存在有效数据时，自动清理"未知"标记

## 常见问题

- **Q: 为什么某些角色没有被正确匹配？**  
  A: 可能是因为Bangumi和Wiki上的角色名称不完全一致，或者是剧情角色/联动角色尚未在Wiki中实装。

- **Q: 如何处理自定义标签？**  
  A: 为角色添加的自定义标签会在后续运行中自动保留。

- **Q: 如何添加新的变体映射？**  
  A: 在`main.py`中找到`special_variants`字典，添加新的变体映射关系。

## 注意事项

- 频繁请求可能被网站限制，建议使用离线模式
- 数据结构可能随着网站变化而需要调整
- 初次运行需要联网获取数据
- 对于在Bangumi上已有独立条目的变体角色，不会进行合并处理

## 扩展与自定义

如需添加新的特殊变体映射关系，可以修改`main.py`中的`special_variants`字典：

```python
special_variants = {
    "送葬人": ["圣约送葬人"],
    "能天使": ["新约能天使"],
    # 添加更多变体映射...
}
```

对于剧情角色等未实装的角色，可以手动编辑生成的`extra_tags.json`文件添加自定义标签。后续运行程序时这些自定义标签将被保留。
